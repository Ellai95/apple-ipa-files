01 / SOURCE

Официальный источник

Избегай неизвестных сайтов, репаков и перезаливов.

02 / VERIFY

Проверка файла

Сверь SHA-256 и подпись с релизом. Контрольная сумма подтверждает целостность, но не доказывает безопасность сама по себе.

03 / UPDATE

Обновление

Android требует прежний ключ подписи. Не удаляй рабочую версию до проверки обновления и повторной активации.
